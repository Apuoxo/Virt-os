# Virt OS

**Цель:** настольная ОС с Windows NT-совместимой архитектурой, запуском Windows-приложений и поддержкой драйверов Windows там, где это подтверждено тестами.

## Исходная база

На первом этапе исследуем [ReactOS](https://github.com/reactos/reactos) как существующую открытую Windows-совместимую ОС. Это отдельная экспериментальная ветка: исходный `main` не меняется, старое bare-metal ядро не используется как основа.

## Принципы

- Никаких заявлений о полной совместимости без проверок.
- Сначала воспроизводимая сборка исходной базы, затем загрузка ISO в QEMU.
- Драйверы проверяются по классам и конкретным устройствам: загрузка, инициализация, работа, восстановление после ошибки.
- Windows-драйверы могут зависеть от версии NT, архитектуры, подписи, интерфейсов ядра и конкретного оборудования.
- Сторонний код и лицензии учитываются явно; ReactOS распространяется под GPL-2.0.
